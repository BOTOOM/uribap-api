# Quickstart: Validate Household Diners and Memory

## Prerequisites

- Dependencies synchronized with `uv sync --locked`.
- Local PostgreSQL integration database is running and reachable.
- The feature branch is based on the API 017 branch and has a single migration parent
  `d3c72b91a84f`.

## Focused tests

Run the new/changed unit, service, REST, MCP, and migration tests:

```bash
uv run pytest \
  tests/unit/domain/test_household_memory.py \
  tests/integration/test_household_memory_service.py \
  tests/integration/test_household_memory_routes.py \
  tests/integration/test_mcp_memory_tools.py \
  tests/integration/test_mcp_transport.py \
  tests/integration/test_migrations.py \
  tests/api/test_household_memory_routes.py \
  -q
```

Add the existing route-authentication tests and any other changed test files to this focused
command. The integration cases verify tenant isolation, uniqueness, optimistic concurrency,
idempotency, privacy-minimized events, active profile behavior, and MCP name resolution.

## Migration round trip

```bash
uv run alembic upgrade head
uv run alembic downgrade -1
uv run alembic upgrade head
uv run alembic heads
```

There must be exactly one head: the new household-memory revision.

## Quality and contract

```bash
uv run ruff check src tests
uv run ruff format --check <each touched Python file>
uv run pyright
PYTHONPATH=src uv run python -m uribap_api.tools.export_openapi
PYTHONPATH=src uv run python -m uribap_api.tools.export_openapi --check
uv run pytest -q
git diff --check
```

Do not hand-edit `openapi/openapi.json`; it must be generated by the exporter.

## Local resource sample

On 2026-10-01, `docker stats --no-stream uribap-api-db-1` reported 0.01% CPU and
66.08 MiB / 31.34 GiB memory (0.21%). No API container was running to sample. The plan adds no
runtime service and defines no separate numeric resource budget.
